# Directory Structure

The repository is organized for clarity, simplicity, and extensibility.

---

## Root Layout

```text
pki-ca-trust/
├── dist/                  # Generated, ready-to-distribute artifacts
│   └── prod/
│       └── internal/
│           ├── ca-trust.pem
│           ├── ca-trust.jks
│           ├── ca-trust.p7b
│           ├── manifest.json
│           ├── checksums.sha256
│           └── package.tar.gz
│
├── config/                 # YAML/JSON configuration files
│   ├── defaults.yaml
│   ├── envs/
│   │   ├── dev.yaml
│   │   ├── prod.yaml
│   │   └── dmz.yaml
│   └── bundles/
│       ├── internal.yaml
│       ├── external.yaml
│       └── os-trust.yaml
│
├── sources/                # Source certificates and metadata
│   ├── internal/
│   │   ├── rootCA.pem
│   │   ├── issuingCA1.pem
│   │   └── metadata.yaml
│   ├── external/
│   │   ├── digicert.pem
│   │   └── globalsign.pem
│   └── os-trust/
│       └── mozilla/
│           ├── certdata.txt
│           └── readme.md
│
├── scripts/ 
│   ├── builder.py        # main build orchestrator
│   ├── verify_certs.py          # validation logic
│   ├── distribute_artifacts.py     # publishing logic
│   ├── converter.py           # CLI entry point for conversions
└── helpers/
|   ├── convert_utils.py           # conversion functions (PEM→JKS, P7B, DER)
|   └── utils.py                # generic helpers (logging, checksum, etc. later)
└── docs/                   # Documentation (this folder)
    ├── 00-overview.md
    ├── 01-design-goals.md
    ├── 02-architecture.md
    ├── 03-directory-structure.md
    ├── 04-config-design.md
    ├── 05-scripts-and-components.md
    └── README.md
```
## Notes

* `/dist/` contains final distributable bundles. No manual edits; regenerated by build process.
* `/config/` defines bundle content and environment behavior.
* `/sources/` is the authoritative CA store.
* `/scripts/` implements logic for building, verifying, and distributing bundles.
* `/docs/` stores every design and maintenance record.

This structure makes it trivial to containerize the project or mount /build as a served directory.
